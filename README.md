# Nume Aplicație  TechNews

## Descrierea temei
TechNews este o aplicatie dedicata pasionatilor de tehnologie. Aplicația oferă utilizatorilor  articole și noutăți despre lansări de telefoane, componente hardware (plăci video, procesoare), inovații în inteligența artificială și software. Utilizatorii pot explora un feed actualizat în timp real, pot citi specificațiile sau detaliile în profunzime și își pot salva articolele preferate (ex: review-uri la gadget-uri sau tutoriale AI) pentru a le citi offline.

## Funcționalități principale (ce vor fi implementate pe viitor)

1. **Feed de Tehnologie (Listă de elemente):** Un ecran principal cu articole din domeniul tech (titlu, imagine reprezentativă, sursă, data publicării).
2. **Ecran de Detalii:** La selectarea unui articol, se deschide un ecran cu descrierea completă a noutății și opțiunea de a accesa sursa originală (ex: The Verge, TechCrunch).
3. **Preluare date (API extern):** Integrare cu [NewsAPI] folosind filtrarea pe categoria "technology" pentru a aduce conținut relevant în timp real.
4. **Favorite (Salvare locală):** Posibilitatea de a marca un articol (ex: lansarea unei noi plăci video) cu o steluță, salvându-l local cu Room Database pentru acces offline.
